PowerShell에서 claude 인식 오류

오류 메시지 · CommandNotFoundException
claude : 'claude' 용어가 cmdlet, 함수, 스크립트 파일 또는 실행할 수 있는 프로그램 이름으로 인식되지 않습니다. 이름이 정확한지 확인하고 경로가 포함된 경우 경로가 올바른지 검증한 다음 다시 시도하십시오.
위치 줄:1 문자:1
+ claude
+ CategoryInfo : ObjectNotFound: (claude:String) [], CommandNotFoundException
+ FullyQualifiedErrorId : CommandNotFoundException
원인환경 변수 PATH에 Claude Code 실행 파일 경로가 없어 터미널이 프로그램을 찾지 못함
해결설치 확인 → PATH 등록 → 버전 확인

1단계 · 설치 확인

PowerShell · 설치 파일 확인
Test-Path "$env:USERPROFILE\.local\bin\claude.exe"

PowerShell · 직접 실행
& "$env:USERPROFILE\.local\bin\claude.exe" --version
버전이 나오면프로그램은 정상 · 터미널이 위치를 모르는 것뿐

Troubleshooting · Windows

2단계 · PATH 등록

PowerShell · 그대로 붙여 넣기
$claudePath = "$env:USERPROFILE\.local\bin"

# 현재 PowerShell에 즉시 적용
$env:Path += ";$claudePath"

# 사용자 PATH에 영구 등록 (중복 방지)
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")

if (($userPath -split ';') -notcontains $claudePath) {
    [Environment]::SetEnvironmentVariable(
        "Path",
        "$userPath;$claudePath",
        "User"
    )
}
고칠 값 없음현재 창에 즉시 적용 + 사용자 PATH에 영구 등록 (이미 있으면 건너뜀) · 관리자 권한 불필요
